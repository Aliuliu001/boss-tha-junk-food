# Boss Thả Junk Food 🍔👹

Game giáo viên chạy ngay trên trình duyệt (không cần cài gì): **Hero (cô/trò) vs Boss**.
Trả lời đúng → gây sát thương / tích mana; sai → Boss phản đòn. Có bảng xếp hạng (Hall of Fame).

## Cách chơi
1. Mở link GitHub Pages của repo này.
2. Bấm **⚙️ Settings** để nhập bảng từ vựng (DATA), chọn ảnh Hero/Boss, và bộ bài skill.
3. Bấm **⚔️ START BATTLE**.

## 4 chế độ chơi
1. Cuộc thi (hết giỏ + hết bàn → End Game)
2. Dò bài Random vô tận (sai làm lại)
3. Lặp vô tận + theo thứ tự + dò bài
4. Theo thứ tự + dò bài + End

## Dữ liệu nằm ở đâu?
Toàn bộ bảng dữ liệu, cài đặt và bảng xếp hạng lưu **ngay trong máy đang chơi** (localStorage).
Muốn chuyển máy / giữ lâu dài → dùng nút **Export CSV** hoặc copy bảng dữ liệu sang Excel.

Bản code `47 cập nhật leaderboard.html` (bản mới nhất, tính điểm theo độ chính xác + sinh tồn).
